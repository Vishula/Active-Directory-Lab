# Active Directory Home Lab - Windows Server 2025 

Welcome to my Active Directory (AD) Home Lab, designed to simulate a small enterprise network using Windows Server 2022 and Windows 11 Pro clients. Built with VMware ESXi for the server host and Oracle VirtualBox for client VMs, it focuses on deploying and managing AD DS, DNS, GPOs, and security controls.

# Key Learning Outcomes 

- Build and manage an Active Directory domain environment. 
- Configure DNS and DHCP services for domain operations. 
- Create and manage Group Policies to enforce security standards. 
- Automate user environment management with logon/startup PowerShell scripts. 
- Create bulk users and groups with PowerShell scripts. 
- Protect infrastructure with encryption and patch management. 
- Implement security policies like password complexity, account lockout, auditing, and firewall rules.

# Tools & Technologies 

- **Oracle VirtualBox** – Virtualization platform 
- **Windows Server 2022 Datacenter Evaluation** – Domain Controller (AD DS, DNS, GPO) 
- **Windows 11 Pro** – Domain-joined clients 
- **Group Policy Management Console (GPMC)** – Policy configuration 
- **PowerShell** – Administration and scripting 
- **Active Directory Users and Computers (ADUC)** – User and group management
